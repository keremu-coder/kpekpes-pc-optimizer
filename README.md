# Kpekpes PC Gaming Optimization

A Windows 10/11 gaming optimizer with verified tweaks, low-latency network tuning, and one-click revert. Built for gamers who want maximum FPS, minimal input delay, and zero bloat.

**By Jesus Kpekpes**

---

## ✨ Features

- **100% Verified Tweaks** — Every change is read back and confirmed, not just applied.
- **MMCSS & Network Tuning** — Disables network throttling, Nagle's Algorithm, and enables RSS.
- **CPU & GPU Priority** — Gives games top scheduling priority and disables GPU power-saving.
- **Xbox Game Bar Removed** — Fully uninstalls Game Bar, Game DVR, and blocks Windows Update from reinstalling it.
- **Aggressive Low-End Mode** — Disables Windows Search, telemetry, and background services for budget PCs.
- **Auto Re-Apply at Logon** — Survives Windows Updates.
- **One-Click Revert** — Restores your PC from an automatic backup.
- **Before → After Score** — See exactly how much was optimized.

---

## 🚀 How to Use

1. Click the green **Code** button at the top of this page, then click **Download ZIP**.
2. Extract the ZIP anywhere (Desktop is fine).
3. **Right-click `Run_Kpekpes.bat`** and select **Run as administrator**.
4. Click **Yes** on the Windows permission prompt.
5. (Optional) Check **Aggressive Low-End Mode** for maximum performance on budget PCs.
6. Click **1. Full Optimize Run**.
7. Wait for the score to reach **100%**.
8. **Restart your PC.**

That's it.

## ⚠️ Antivirus Warning

Because this tool modifies system settings (which is the whole point), Windows Defender or third-party antivirus may flag it as a "HackTool" or "PUA". This is normal for any optimization tool.

If you see a **"Windows protected your PC"** blue popup:
- Click **More info**
- Click **Run anyway**

---

## 🔄 How to Undo Everything

1. Open the tool again.
2. Click **3. Revert to Original**.

The tool restores your PC from the backup it created on the first run.
